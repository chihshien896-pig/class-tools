# 遊戲開發設計書：軍艦棋數學對戰 (Battleship Math Duel)

## 1. 專案概述
「軍艦棋數學對戰」是一個結合數學運算與策略棋類遊戲的網頁應用。老師可以開設不同題型的房間，學生透過 QR code 進入後，必須答對數學題目才能獲得攻擊機會。

## 2. 核心遊戲機制
### 2.1 棋盤邏輯
- **網格系統**：標準 10x10 網格（或可自訂大小）。
- **軍艦配置**：每位玩家在遊戲開始前放置不同長度的軍艦（例如：1x4, 1x3, 1x2 等）。
- **攻擊模式**：
    - 學生答對一題數學題後，獲得一次「投擲炸彈」的機會。
    - 若答對速度快，則冷卻時間短，可以更頻繁地答題並攻擊。

### 2.2 數學題目與類型 (國小五六年級程度)
題目將由系統自動產生，老師可依教學進度選擇以下類別：

#### **【五年級重點】**
1.  **因數與倍數**：尋找因數、公因數、判斷質數。
2.  **異分母分數加減**：需進行通分運算。
3.  **多位小數運算**：三位以上小數的乘法。
4.  **百分率與比率**：折扣計算、百分率轉換。
5.  **未知數運算**：簡單的等量公理與未知數（x）求值。

#### **【六年級重點】**
6.  **最大公因數與最小公倍數**：應用題型或直接運算。
7.  **分數除法**：包含帶分數與真分數的除法運算。
8.  **小數除法**：除數為小數的除法、求餘數。
9.  **比與比值**：最簡整數比的化簡、正比應用。
10. **速率計算**：距離、時間與速率的換算。
11. **圓周長與圓面積**：使用 3.14 進行相關計算。

### 2.3 角色與流程
- **老師 (Host/Admin)**:
    - 登入後選擇「創立房間」。
    - 指定該房間的題目類別（1-5 類）。
    - 產生房間代碼與 QR code。
    - 監控對戰狀態（選擇性）。
- **學生 (Player)**:
    - 掃描 QR code 進入房間。
    - 準備階段：放置自己的軍艦。
    - 對戰階段：答題 -> 獲取炸彈 -> 點擊對手棋盤進行攻擊。

## 3. 技術架構
- **前端 (Frontend)**: 
    - HTML5 / CSS3 (Vanilla CSS, Premium Aesthetic)
    - JavaScript (ES6+)
- **後端與同步 (Backend/Sync)**:
    - **Firebase Realtime Database**: 用於即時同步玩家操作、棋盤狀態與答題進度。
    - **Firebase Hosting**: 用於部署應用程式。
- **功能模組**:
    - `MathEngine`: 負責隨機產生題目與驗證答案。
    - `GameController`: 處理遊戲狀態機（等待、配置、對戰、結束）。
    - `SyncManager`: 處理 Firebase 資料同步。

## 4. UI/UX 設計風格 (Visual Excellence)
- **主題**：現代軍事科技感 / 霓虹電子風格。
- **色彩計畫**：
    - 深藍色背景 (#0a0e17)
    - 霓虹藍 (軍艦/友軍資訊)
    - 鮮艷紅 (爆炸/敵軍受損)
    - 螢光綠 (正確答案/系統狀態)
- **互動效果**：
    - 點擊炸彈時的震動與粒子效果。
    - 答對時的微動畫回饋。
    - 平滑的畫面切換與轉場。

## 5. 開發時程建議
1.  **Phase 1**: 基礎架構與 Firebase 設定。
2.  **Phase 2**: 數學題目產生器 (MathEngine) 開發。
3.  **Phase 3**: 雙人對戰邏輯與即時同步。
4.  **Phase 4**: UI 美化、音效與動畫強化。
5.  **Phase 5**: QR code 產生與老師管理介面。
